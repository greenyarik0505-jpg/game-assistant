# 🎮 Game Assistant (Ігровий Помічник)

Сучасна зручна програма-оверлей для геймерів з багатим функціоналом.

## 🚀 Основні можливості (Features)

* ⚡ **Монітор FPS** — відображення поточної частоти кадрів.
* 💾 **Моніторинг та Очистка RAM** — відстежує завантаження оперативної пам'яті та дає можливість швидко її звільнити (кнопка `🧹 Очистити RAM`).
* ⏱️ **Ігровий Таймер** — підрахунок часу вашої ігрової сесії з можливістю паузи та скидання.
* 📝 **Швидкі Нотатки** — зручний блокнот прямо у додатку з автоматичним збереженням у `game_notes.txt`.
* 📌 **Режим "Поверх усіх вікон" (Topmost)** — перемикач, що утримує утиліту поверх ігор та інших додатків.
* 🔍 **Компактний Міні-оверлей (Mini Mode)** — можливість згорнути програму у маленьке плаваюче віконце для економії місця на екрані.

---

## 📦 Запуск та Інсталяція

### 1. Готовий файл (.exe)
Запустіть файл з папки `dist`:
```cmd
dist/game_assistant.exe
```

### 2. Запуск з сирцевого коду (Python)
Вимоги: Python 3.x
Встановіть залежності:
```bash
pip install customtkinter psutil
```
Запустіть додатком:
```bash
python game_assistant.py
```

---

## 🛠️ Збирання у EXE (Build)

Для перезбирання виконайте:
```bash
python -m PyInstaller --noconsole --onefile game_assistant.py
```
Готовий `.exe` буде у теці `dist/`.
